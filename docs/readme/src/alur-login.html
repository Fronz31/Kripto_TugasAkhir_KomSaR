Alur login tiga faktor

Login hanya dari aplikasi desktop. Setiap faktor diperiksa di server; sesi baru dibuat setelah faktor terakhir lolos.

Faktor 1

Dongle

Colokkan flashdisk. Aplikasi membaca KOMSAR.DONGLE dan server mencocokkan SHA-256 token serta serial volume.

Faktor 2

Username dan password

Dicek terhadap hash Argon2id bersama bukti dongle.

Lolos: sesi sementara, berlaku 3 menit.

Faktor 3, login berikutnya

Verifikasi suara

Tahan tombol dan ucapkan kalimat acak empat kata. Lolos bila skor cosine mencapai ambang.

Faktor 3, login pertama

Ganti password, daftar suara

Ganti password sementara dari admin, lalu rekam tiga kalimat acak. Profil suara disimpan terenkripsi AES-256-GCM.

Beranda

Sesi penuh, maks. 8 jam

Lima kali password salah, atau tiga kali suara salah, mengunci akun selama 15 menit. Pesan galat password dan dongle selalu sama, sehingga tidak membocorkan faktor mana yang gagal.
