Alur kriptografi pesan

Isi dienkripsi sekali. Kunci pembukanya dibungkus dan disembunyikan terpisah untuk setiap penerima.

Pengirim

  1. Tulis pesan dan kunci rahasiaPilih satu atau beberapa penerima dengan username.
  2. Buat CEK acak 32 byteHKDF menurunkan subkey terpisah untuk tiap lapis.
  3. Vigenère, lalu AES-256-GCMPesan penting dibungkus satu lapis AES‑256‑GCM lagi dengan kunci turunan master key.
  4. Bungkus CEK per penerimaKunci pembungkus = Argon2id(kunci rahasia, User ID penerima, salt) + HKDF.
  5. Sembunyikan kunci rahasia di PNGLSB; posisi bit diacak keystream ChaCha20 dari User ID penerima.

Basis data

  • Ciphertext (sekali)
  • CEK terbungkus, satu per penerima
  • Gambar stego, satu per penerima

Tanpa User ID dan kunci yang benar, AES-GCM menolak; tidak ada hasil setengah jadi.

Penerima

  1. Pilih pesan, masukkan User IDGambar steganografi pesan itu ditampilkan.
  2. Kunci diekstrak dari gambarUser ID salah membaca posisi bit yang salah, lalu ditolak.
  3. Ketik ulang kunci rahasiaLima kali salah: ulangi dari langkah 6.
  4. Buka CEKArgon2id(kunci, User ID, salt) membuka CEK yang dibungkus.
  5. Dekripsi isiAES-256-GCM, lalu Vigenère dibalik. Hasil hanya disimpan di memori server.
